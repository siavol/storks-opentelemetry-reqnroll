## Agent skills

### Issue tracker

Issues и спеки ведутся как локальные markdown-файлы в `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Стандартные пять меток: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: один `GLOSSARY.md` и `docs/adr/` в корне. See `docs/agents/domain.md`.

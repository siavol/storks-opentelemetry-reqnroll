## Agent skills

### Issue tracker

Issues and specs are kept as local markdown files in `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The standard five labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the root. See `docs/agents/domain.md`.
